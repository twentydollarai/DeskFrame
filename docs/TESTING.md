# Testing scope

The historical 0.1.0 package has recorded Windows 11 x64 results: 2,371 rendering checks, 241 movement checks, 52 window-only checks, 16 portable process checks, 505 opacity/recovery/accessibility-provider checks and 19 fresh-ZIP launcher/movement/persistence/restart checks. An obstructed opacity capture failed first; its unobstructed rerun passed. Private raw records are not published with this repository. The source harnesses are included for inspection; these summaries are not a new test run.

Human acceptance records cover transitions, Fit/Fill, corners, portable restart, tray-disabled controls, recovery, Settings, folder selection, the tested display layouts, movement buttons and shortcut warnings. Screen-reader speech was deferred. Full legacy picker automation is not included in final certification.

## Read-only package verification

`tests/verify-package.ps1` reads the archive in memory, checks the pinned 1.0.0 ZIP/checksum/entry hashes and exact allowlist, scans text in multiple encodings, and compares packaged documentation/configuration with source copies. It neither extracts nor builds nor executes the application. Provide `-ZipPath`, `-ChecksumPath` and a nonempty `-PrivatePatterns` array of regular expressions covering the release owner's private account/project identifiers. Keep that list outside the public repository; use variables or an interactive prompt rather than committing sensitive literals or command history. The list is required, not silently omitted. Generic profile-path and credential patterns supplement it. Review all intended public images visually; a byte scan cannot read screenshot text.

Pinned hashes intentionally make this checker specific to the verified 1.0.0 candidate. A developer rebuild or newly packaged archive is not certified by this check. Private backup preservation is audited separately and is not reproducible from public files.

## Development harnesses

The C# sources under tests retain the original rendering, movement, window-only, legacy integration and targeted beta harnesses. PowerShell wrappers are included where available. `build.ps1 -Tests` selects the legacy Integration.cs harness, whose old full-suite opacity expectations require maintenance before reuse with the current layered presentation. Do not interpret it as the certified window-only suite. The legacy orchestration script that rebuilt and repackaged automatically is deliberately excluded.

rendering.ps1 builds and launches rendering tests. beta-regression.ps1 builds a harness and drives a specified executable. process-smoke.ps1 depends on fixtures generated by native integration. These scripts create files and may open windows or interact with the desktop; they are not read-only publication checks. Run only in an isolated disposable environment with no personal profile or competing DeskFrame instance. See RELEASE_NOTES.md for the focused checks performed for 1.0.0. Broader historical acceptance was not repeated.

See [manual acceptance](MANUAL_ACCEPTANCE.md) for the remaining coverage. A missing test result is not evidence of a defect.
